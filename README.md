# japanese-news

Weekly news packs for a personal Japanese-learning app. Release assets only (`news.db.gz`, `manifest.json`).

Article text comes from Japanese Wikipedia, [Portal:最近の出来事](https://ja.wikipedia.org/wiki/Portal:最近の出来事), licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The packs are under the same licence.
